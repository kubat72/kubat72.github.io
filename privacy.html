Privacy policy

Ductor backup uses the Google Drive API with the drive.file scope only. It can access only the files that it has created itself in the owner's Google Drive; it cannot see any other files.

The tool runs on the owner's own computer. Backups are encrypted before upload. No data is collected, stored on third-party servers, shared, sold or used for advertising.

Access can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
